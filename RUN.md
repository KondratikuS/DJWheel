# Запуск на стенде

Приложение — один HTML-файл, серверу ничего считать не надо. Нужны: Windows, Chrome (или Edge), Python 3
(любой, без пакетов) и, если есть, дека Pioneer по USB.

## 1. Забрать проект

```bash
git clone https://github.com/KondratikuS/DJWheel.git
cd DJWheel
git checkout midi-input
```

Ветка `midi-input` — рабочая (пары треков, скретч, XDJ-XZ). В `main` лежит старая сенсорная версия с вопросами,
она не нужна. Исходные WAV заказчика в репозиторий не входят (183 МБ, папка `tracks/`), в игре уже лежат
готовые OGG в `app/audio`.

## 2. Запустить

Сначала один раз `tools\check.cmd` — покажет, есть ли Python и Chrome, видна ли дека, свободны ли порты.

```bash
tools\start.cmd
```

Открывает два окна: мост (для Resolume / grandMA, окно «DJ Wheel bridge») и сервер игры на
`http://localhost:8090/`, страница сама открывается в браузере. Первое касание экрана включает звук и первую
пару треков (браузер не даёт звук без жеста). Полный экран — F11. Закрыть стенд — закрыть оба окна.

Только игра, без моста — `tools\serve.cmd`; только мост — `tools\bridge.cmd`.

Без Python и без git: скачать `DJWheel.html` из раздела Releases репозитория и открыть двойным щелчком —
всё внутри одного файла (21 МБ), работает с диска. Вкладка «Выходы» в настройках без моста недоступна.
В репозитории файл не лежит (`dist/` в `.gitignore`), пересобрать после правок: `python tools/pack_single_file.py`.

## 3. Управление

| Что | На экране | С клавиатуры | С деки |
|---|---|---|---|
| Скретч | тянуть любой диск | — | джог (на XDJ-XZ: CONTROL MODE, LINK → LOAD, VINYL включён) |
| Кроссфейдер между треками пары | тянуть ручку внизу микшера | ← → (или A / D) | кроссфейдер |
| Пауза / пуск | кнопка PLAY/PAUSE на любой деке | пробел | PLAY |
| Следующая пара | кнопка CUE на любой деке | N | CUE |
| Темп обоих треков ±10 % | ползунки TEMPO на деках | ↑ ↓ | TEMPO любой деки |
| Громкость, низкие, средние, высокие | четыре фейдера каналов (3 1 2 4) | — | фейдеры каналов |
| Семплы | 16 падов | — | пады обеих дек |
| Старт | касание экрана | — | PLAY (звук всё равно включится после первого касания экрана) |
| Настройки | шестерёнка в правом верхнем углу | S | — |

Диагностика MIDI — клавиша **D** (что пришло с деки и что игра с этим сделала), мастер привязки — **M**
(или пять быстрых тапов в левом верхнем углу).

**Окно настроек** (шестерёнка / S), две вкладки:
- **ДЕКА** — что к чему привязано у подключённой деки; «Переучить» напротив любой функции (одна кнопка,
  колесо или регулятор), «Мастер целиком», «Сбросить профиль», диагностика.
- **ВЫХОДЫ** — карта событий игры → OSC в Resolume и grandMA и MIDI: адреса хостов и портов, имя MIDI-выхода,
  основной выход — 16 падов, у каждого своя строка; ниже события игры; для каждой строки список действий (OSC-адрес с аргументами или MIDI-сообщение), «Проба» шлёт пробное
  событие, «Сохранить на мост» пишет `tools/bridge.json`, мост перечитывает сразу. Вкладка работает только при
  запущенном `tools\bridge.cmd`.

## 4. Дека

Подключить по USB до открытия страницы. Chrome спросит разрешение на MIDI — разрешить. Знакомая дека
(DDJ-FLX6) работает сразу; незнакомая, в том числе XDJ-XZ, при первом сигнале открывает мастер: три оборота
левого колеса → проверка → три оборота правого → проверка → 16 падов → PLAY → CUE → кроссфейдер → четыре фейдера
каналов → темп левой деки → темп правой. Оба колеса скретчат, оба темпа задают общий темп. Каждый шаг можно
пропустить, «Закрыть» сохраняет профиль в браузере (localStorage) — повторять не придётся.

XDJ-XZ видна как два порта «XDJ-XZ (1)/(2)», это нормально: профиль общий. Джог шлёт MIDI только в CONTROL MODE.

## 5. Мост в Resolume / grandMA (по желанию)

```bash
tools\bridge.cmd
```

Слушает события игры на `http://localhost:7777/ev` и шлёт OSC: Resolume на 7000, grandMA на 8000 (gma3), плюс
MIDI в виртуальный порт «DJ Wheel Out» — его создаёт `tools\midi_loop.cmd` (нужны Windows MIDI Services Tools,
`winget install Microsoft.MIDI.SDK`; петля живёт до перезагрузки). Что куда слать — `tools/bridge.json`,
события: `pad`, `pair`, `next`, `scratch`, `mix`, `tempo`, `chan`, `play`, `cue`, `start`. Проверка без программ:
`python tools/osc_listen.py 7000 8000`.

## 6. Настройка на стенде — по порядку

1. Дека в USB, затем `tools\start.cmd`. Chrome спросит про MIDI — «Разрешить».
2. На XDJ-XZ: CONTROL MODE, LINK → LOAD на обеих деках, VINYL включён. Нажать **D** и покрутить колесо —
   в диагностике должны бежать сообщения.
3. Нажать **M**, пройти мастер (колёса, пады, PLAY, CUE, кроссфейдер, каналы, темпы). Профиль остаётся
   в этом Chrome на этом компьютере; переустановили браузер — пройти снова.
4. Resolume: Preferences → OSC → Enable OSC Input, порт 7000. grandMA3: Menu → Network → OSC, вход 8000,
   префикс gma3. Если Resolume или MA на другом компьютере — в настройках игры, вкладка **ВЫХОДЫ**, вписать
   его IP в адрес хоста и «Сохранить на мост» (пишется в `tools/bridge.json`).
5. Там же назначить, что шлёт каждый из 16 падов: OSC-адрес с аргументами или MIDI-нота. «Проба» шлёт
   сообщение сразу — удобно проверять, принимает ли Resolume. В MIDI-порт «DJ Wheel Out B» Resolume и MA
   видят только при установленных Windows MIDI Services (`winget install Microsoft.MIDI.SDK`), иначе
   остаётся OSC.
6. Обновление со временем: `git pull` в папке проекта, затем Ctrl+F5 в браузере.

## 7. Если что-то не так

- Страница не открывается — сервер не запущен (после перезагрузки его надо поднимать заново).
- Поменяли фон или раскладку, а в браузере старое — Ctrl+F5.
- Звука нет — коснуться экрана; жёлтая плашка внизу напоминает об этом.
- `DJWheel.html` с диска играет семплы, но не треки — старая сборка (до 29.10 вечера): с file:// Chrome не
  грузил модуль воркета из blob-ссылки, теперь есть запасной путь через data:. Скачать свежий файл из Releases.
- Дека не реагирует — нажать D и покрутить: если сообщений нет, проверить CONTROL MODE и USB; если есть,
  но «нет профиля» — нажать M и пройти мастер.
- Новые треки — положить в `tracks/` и выполнить `python tools/prep_tracks.py` (нужны scipy, torch, PyAV,
  ffmpeg с rubberband; на стенде этого может не быть — лучше готовить на основной машине и коммитить OGG).
