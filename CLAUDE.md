# DJ Wheel

Второй веб-опрос (после Interp The Sound): «какой ты диджей». Чистый HTML/JS,
`app/index.html` + картинки в `app/img/`, без Unity и сборки. Кадр 16:9, работает
на планшете и в браузере, открывается двойным щелчком (сервер не нужен; шрифты
с Google Fonts, без сети берётся системный).

## Сценарий

1. **Старт** — табло с заголовком, колесо, кнопка START в центре диска.
2. **Пять вопросов** — вопрос на табло, шесть ответов секциями кольца на верхних 180°,
   на фоне тихо играет второй трек (`DATA.bgTrack`, пока синтетический пад).
   Пользователь крутит диск (тап/мышь), зелёный маркер указывает секцию. Подтверждения
   нет: **отпустил — выбрал**, задержался на секции 2 с (`dwellMs`) — выбрал, тап по
   секции — выбрал. **Резкий рывок** (`flickVel`) — рулетка: маркер мечется по дуге и
   встаёт на случайную секцию, табло пишет RANDOM!. Ступица в центре показывает N/5.
3. **Финал** — «Собираем твой сет…» 2 с, фон гаснет, потом затемнение поверх колеса
   (табло не затемняется), название профиля и описание печатаются по буквам, диск
   крутится сам, на табло эквалайзер от WebAudio-анализатора, играет трек профиля.
   Загораются четыре пада дека (верхний ряд больших падов под PAD MODE, синяя обводка
   как на фото) с семплами KICK / HAT / CLAP / SNARE (`DATA.samples`, пока синтез),
   светодиоды каналов на обеих панелях работают эквалайзером под затемнением, табло
   поверх. Пады: все разом вспыхивают на своём месте (без звука — заказчик просил) и за
   0.9 с разъезжаются крупно под описание, группа по центру кадра (`PAD_TARGET`);
   при НАЗАД возвращаются
   (`padsHome`). Кнопка НАЗАД — снизу по центру, появляется после переезда падов.
   START заодно просит полный экран (`goFullscreen`, только по жесту; iPhone Safari
   не умеет — там режим «На экран Домой» через meta `apple-mobile-web-app-capable`
   и inline-манифест `display: fullscreen`; в артефакте claude.ai это не работает,
   нужен свой хостинг). Подсказка «жми старт» — на диске под кнопкой.

## Данные

Всё в объекте `DATA` в начале скрипта: `questions[5].options[6].{text, score[4]}`,
`profiles[4].{name, text, track}`. Профиль — по максимуму суммы баллов, ничья случайно.
`track` — URL/путь к mp3; пока `null`, тогда играет синтетический техно-луп
(`makeBeat`), чтобы эквалайзеру было что показывать. `listenSeconds` — сколько играть
на финале.

Тексты и треки ещё не присланы: сейчас заглушки «ВОПРОС N», «ВАРИАНТ N».
Когда придут — заменить `DATA`; при длинных ответах кегль в секции подбирается
по длине (`fillRing`), больше ~16 символов не влезает.

## Картинки — из фото Pioneer DDJ-FLX6

Реф заказчика `ref/ddj-flx6.webp` (2000×2000, пульт сверху на белом). Всё делает
`tools/build_bg.py`, нейросеть больше не нужна:

- кадр 1920×1080 = [копия микшерной панели, фото x 722..1150] + [левый дек + микшер,
  x 26..1150]; масштаб 1.2371 подобран так, чтобы вместе вышло ровно 1920, по высоте
  срез 10 px сверху (остальное снизу). Стола и мастер-секции нет — заказчик попросил
  обрезать края. Копия панели делается ДО затемнения, поэтому обе стороны одинаковые;
- логотипы DDJ-FLX6 и Pioneer DJ закрашены цветом панели; оригинальные фейдеры не трогаем;
- всё притемняется ×0.62 под второй реф; джог (центр (376, 933), внешний r 312 по профилю
  яркости) → `wheel.png` с альфой; вращается весь джог вместе с ребристым кольцом
  (`PLATTER_R` = внешний радиус, заказчик так попросил 25.09);
- `app/layout.js` — доли кадра: джог, 4 пада (верхний ряд больших под PAD MODE, рамки
  по синей подсветке), 8 столбиков LED-индикаторов каналов × 6 светодиодов с цветами.
  На старте/вопросах светодиоды горят как на фото (свои поверх фото), на финале
  прыгают по 8 полосам спектра трека. Без layout.js — запасная раскладка.

Первые пробы (`gen_assets.py`, `crop_circle.py`, аутпейнт стола) остались как инструмент,
в деле не используются.

## Один файл для заказчика

`python tools/pack_single_file.py` → `dist/DJWheel.html` (~4.2 МБ): картинки из `app/img`
и `layout.js` вшиты внутрь (динамические картинки — через словарь `IMG`), открывается
двойным щелчком. Пересобирать после любой правки `app/`.

## Git и ветка с MIDI

01.10.2026 — папка стала репозиторием (локальным, без remote). `main` = сенсорная версия
(артефакт v8, коммит `3974dfe`), её не трогаем. Работа с живой декой — в ветке
`midi-input`. В гите нет `dist/`, `tools/out/`, `ref/parts/`.

Задумка: Web MIDI (Chrome/Edge на ПК или Android; на iOS Web MIDI нет, нужен https или
localhost). Джог → вращение колеса, касание/отпускание джога → выбор, пады → семплы,
режим привязки «покрути / нажми», чтобы подошла любая дека. Коды левого дека DDJ-FLX6
по маппингу Mixxx (github.com/fixxiefixx/DDJ-FLX6-Mixxx-mapping, на железе НЕ проверено):
джог бок `B0 21`, платтер `B0 22` (vinyl) / `B0 23`, пады Hot Cue `97 00..07`,
PLAY `90 0B`, CUE `90 0C`. Готового эмулятора DDJ в сети нет — тест без деки: виртуальный
loopback-порт (встроенный Windows MIDI Services либо loopMIDI) + своя страница-эмулятор,
шлющая эти же коды.

**Стенд MIDI на этом ПК (01.10.2026).** Поставлен пакет `Microsoft.MIDI.SDK`
(winget, Windows MIDI Services Runtime and Tools 1.0.16-rc.3.7) в
`C:\Program Files\Windows MIDI Services\Tools`. Петля: `tools/midi_loop.cmd` →
`midi loopback create --name-a "DJ Wheel A" --name-b "DJ Wheel B"` (что послано в A,
приходит из B и наоборот; MIDI 1.0-приложения видят по два входа и выхода). Она
временная — до перезапуска службы MIDI или ПК; постоянную делает приложение MIDI Settings.
`midi basic-loopback create` на этой сборке падает с ошибкой — не использовать.
Консольные `midi ... monitor / send-message` требуют настоящей консоли (из скрипта с
перенаправлением вывода не работают) — проверка петли своя: `tools/midi_loop_check.py`
(winmm через ctypes, без библиотек), прошла: `B0 22 41`, `B0 22 3F`, `97 00 7F` дошли.
Встроенный браузер Claude Web MIDI не разрешает (NotAllowedError) — проверять в Chrome:
`app/midi-test.html` (список портов, монитор входов, тестовая посылка в петлю).

**Слой MIDI (01.10.2026, ветка `midi-input`).** `app/midi.js` подключён в конце
`index.html` (в однофайловую сборку вшивается). Логика:

- знакомая дека — таблица `KNOWN` по имени порта (пока только DDJ-FLX6: джог `B0 21/22/23`,
  значение − 64, 7200 тиков на оборот, пады `97 00..03`, кнопка PLAY `90 0B`; датчик
  касания в маппинге не нашёлся — без него выбор по тишине 600 мс);
- незнакомая дека — при первом её сообщении открывается мастер: «один полный оборот по
  часовой» (сам определяет CC, кодировку шага — 64±n / дополнительный код / абсолютная
  позиция, знак, тики на оборот и ноту касания), потом пады KICK/HAT/CLAP/SNARE и кнопка
  СТАРТ/НАЗАД (любой шаг можно пропустить). Профиль — в localStorage по имени порта.
  Вручную мастер: клавиша M или пять быстрых тапов в левом верхнем углу;
- игра: тики → угол колеса; убрал руку (или тишина без датчика, или держишь 2 с) — выбор;
  поворот меньше 3° не считается (случайный толчок); рывок ≥ `flickVel` — рулетка;
  пады играют семплы только на финале; кнопка — START на старте и НАЗАД на финале;
- `MIDI.feed('порт', [байты])` — подать сообщение руками, `MIDI.reset()` — забыть профили.

Проверка без деки: `app/midi-emu.html` — диск (середина с касанием, обод без), 8 падов,
CUE/PLAY, три набора кодов (как FLX6 / незнакомая / абсолютный энкодер), шлёт в «DJ Wheel A»,
приложение слушает «DJ Wheel B». Окна ставить рядом: в фоновой вкладке браузер
останавливает анимацию (рулетка не докручивается). Звук: MIDI — не жест пользователя,
поэтому при старте только с деки Chrome держит звук выключенным до первого тапа по экрану;
для киоска — запуск Chrome с `--autoplay-policy=no-user-gesture-required`.
Прогнано через `MIDI.feed`: мастер, выбор отпусканием/тишиной/удержанием, защита от толчка,
рулетка, пады, старт и назад. В настоящем Chrome с петлёй и на живой деке — ещё нет.

Правки после первой пробы пользователя в Chrome (01.10): «сам выбирает», нет звука, угол
эмулятора не совпадает с игрой. Причины и что сделано: (1) мастер закрывал шаг колеса через
1,2 с тишины, пока рука ещё на диске, и первое сообщение (обычно касание) тратилось на
открытие мастера — касание не запоминалось, выбор шёл по тишине; теперь первое сообщение
идёт в зачёт, шаг ждёт, пока уберут руку. (2) Тишина без датчика 0,6 → 1 с. (3) Рулетка
с деки — только от настоящего раскрута (`CFG.spinVel` 30°/кадр и `spinMove` 150°), быстрый
поворот к секции её больше не включает. (4) Звук: подсказка «коснись экрана» (`#soundHint`),
любой тап/клавиша будит AudioContext. (5) Чувствительность = 360° / тики за оборот в мастере;
мышью ровно оборот не сделать — в эмуляторе кнопка «Ровно один оборот» и счётчик градусов.
