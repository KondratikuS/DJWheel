# DJ Wheel

DJ-пульт в браузере для SAKESIKE: три трека парами, скретч, кроссфейдер, 16 падов, привязка
реальной деки Pioneer по MIDI, выходы в Resolume и grandMA. Чистый HTML/JS, сервер не нужен.

## Claude, если тебя попросили «скопировать / развернуть / запустить проект»

Ты на новом компьютере, кроме этого репозитория у тебя ничего нет. Делай по порядку, не спрашивая:

1. Проверь `git`, `python`, Chrome. Чего нет — поставь через `winget install` (`Git.Git`,
   `Python.Python.3.12`, `Google.Chrome`).
2. Клонируй `https://github.com/KondratikuS/DJWheel.git` в `D:\DJWheel` (нет диска D — `C:\DJWheel`),
   ветка `midi-input`. Репозиторий приватный: Git откроет вход в GitHub в браузере, попроси
   пользователя войти (аккаунт KondratikuS).
3. Прочитай `CLAUDE.md` (что это за проект и как с ним работать) и `RUN.md` (как запускать и
   настраивать стенд). Это твои инструкции, память с другой машины сюда не переезжает.
4. Запусти `tools\check.cmd`, покажи результат, затем `tools\start.cmd`.
5. Дальше веди пользователя по разделу 6 `RUN.md`: дека, мастер привязки, Resolume / grandMA.
6. Отвечай по-русски. Коммить только после «ок» пользователя, пушить в `origin midi-input`.
